# Go Todo API moved to its proper service repository

The supported example is [service-lasso/lasso-todo-api](https://github.com/service-lasso/lasso-todo-api), generated through GitHub's service-template flow. It owns its Go source, manifest, package/test/verify, platform assets and CI.

Follow the [advanced tutorial](../../docs/getting-started/advanced-add-go-todo-api-service.md). The former Core-owned build helper/sketch is superseded by Core#1666; do not copy a Go payload out of Core.
