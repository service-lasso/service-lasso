# Choose how to run Service Lasso

Choose the path that matches what you need to own:

- Use the checked-in Core baseline when you are evaluating or contributing to Service Lasso. Follow [Quick start](quick-start.md).
- Use a reference app when you are integrating the runtime into an application. [Choose a reference app](reference-apps.md) for Node, web, desktop, and executable-packaging examples.
- Use the published runtime package when an app already owns a `services/` inventory. Follow [Use Service Lasso in your app](integration/README.md).

Core releases have lean and bundled artifacts. The lean form expects an app or operator to provide the service inventory and allows acquisition during install/start; the bundled form contains the baseline inventory and pre-acquired archives. The [Reference Apps](reference-apps.md) page explains the packaging trade-offs without making a service-specific deployment claim.
