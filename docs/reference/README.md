# Technical reference

These pages define the stable shared contracts used by service authors, app hosts, and operators. They are not operational runbooks; use [Run and manage services](../operations/README.md) when the immediate goal is to operate an existing inventory.

- [Manifest fields and health checks](service-json-reference.md) and [healthcheck reference](healthcheck-reference.md)
- [CLI commands](readiness-gate.md) and [service action inputs](service-action-inputs.md)
- [HTTP APIs](product-api-facade.md), [Operator MCP](operator-mcp.md), and [runtime capabilities](runtime-capabilities.md)
- [Configuration and state](runtime-instance-registry.md), [dependencies and endpoint allocation](endpoints-contract.md), and [workflow packages and execution](workflow-package-catalog.md)

Contract history, implementation plans, test matrices, and release evidence remain separate records in the [documentation map](../documentation-map.md). Their presence is not a promise of present product behavior.
