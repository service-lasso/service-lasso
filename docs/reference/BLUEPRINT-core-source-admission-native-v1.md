## Decision, existing source and alternatives

Actual Core src/server/index.ts already owns trusted middleware, resolved workspace, service permission/confirmation/lifecycle routes. Existing Audit store uses appendFile and returns an existing event ID without exact payload equality; existing command confirmations write independent stores. Neither provides this journal transaction or durable native Audit. Current discovery uses path-based interfaces and cannot assert held-handle exclusion/readback. Existing released registration and staged Windows ZIP/Linux TAR stay separate.

The outcome contract defines native durability but does not define provider ABI, key custody, journal binary schema, complete private nativeTemplate body or positive proof producer. Silently implementing a JS adapter over writeFile/rename/lstat or inventing a callback returning durable:true would create unreviewed authority. Selected proposal: a dedicated Core-owned native admission companion with narrowly confined capabilities, authenticated original Core process, provisioned persistent key provider, held trusted workspace/storage/root identities, versioned binary commands and independently admitted observer. It performs native storage/asset reads/materialization/discovery; Core alone authenticates API actors, validates canonical semantics and authorizes no-lifecycle requests. It is not CLI39's external host session broker, a privileged policy parser, generic shared event platform or arbitrary path executor. Owner provisioning is absent today and requires separate authorization; no new service is launched by this blueprint.

Pure in-process JS cannot establish no-follow atomic no-replace plus actual durable directory semantics on both hosts. A generic filesystem broker would widen authority unnecessarily. A per-request compiler/helper has mutable tool and child-custody gaps. The dedicated compiled matching native companion is selected; missing image/profile/key/native capability fails503 before stage allocation. Rollback disables admission and retains all original evidence/state; it never resets/migrates or falls back.
