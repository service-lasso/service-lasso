## Decision, existing source and alternatives

Actual Core src/server/index.ts already owns trusted middleware, resolved workspace, service permission/confirmation/lifecycle routes. Selected proposal: a dedicated Core-owned native admission companion with narrowly confined capabilities, authenticated original Core process, provisioned persistent key provider, held trusted workspace/storage/root identities, versioned binary commands and independently admitted observer. Owner provisioning is absent today and requires separate authorization; no new service is launched by this blueprint.

A per-request compiler/helper has mutable tool and child-custody gaps. The dedicated compiled matching native companion is selected; missing image/profile/key/native capability fails503 before stage allocation.
