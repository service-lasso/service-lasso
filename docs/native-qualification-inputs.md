# Native qualification input intake

Purpose: define what must be supplied before native entry can be proved. This
document does not supply or synthesize authority.

## Required authentic originals

- Nine-section `SLCPROF1` profile and its issuing authority.
- Closed Go/C ABI definition and the complete 77-field geometry.
- Genuine constructors and domain/family/provider/finance/custody owner records.
- Windows query/tool/source/environment originals.
- Matching native host and attempt owners.
- Custody/toolchain originals that bind the above to the exact candidate bytes.

## Required joins

- `security_label_bytes` = `securityLabelBytes`
- `terminal_calls` = `terminalCalls`
- `body_bytes` = `representationBytes`
- `requests` = `terminalCalls + 1`

`representation_bytes` is not accepted for `body_bytes`.

## Required admission sequence

1. Intake evidence into an owner-controlled private store; record hashes and
   original filenames without rewriting content.
2. Perform a distinct full-source review outside the implementation lane.
3. Issue a NEW complete actual-input ROOT admission for the exact evidence set.
4. Obtain literal parent admission for the same set.
5. Execute Linux and Windows native lanes from the admitted inputs.
6. Qualify the resulting Core/CLI/TUI candidate.
7. Release owner issues GA; implementation cannot self-issue ROOT or GA.

## Explicit non-substitutes

- Synthetic/dev fixtures, bundle-to-image mapping, placeholder profile fields,
  generated geometry, and locally manufactured owner tuples do not qualify.
- A green v2 source test, mutable fixture, or terminal E2E does not establish
  native authenticity or release authority.
- macOS privileged-helper/ConPTY lanes remain environment-blocked and are not
  evidence for these inputs.

## Evidence receipt fields

Each supplied original must retain: owner, source system, acquisition method,
timestamp, content hash, content length, parent/child relationships, and the
exact candidate source commit and artifact digest it is claimed to authorize.
