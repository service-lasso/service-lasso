# Getting started

This is the newcomer path for Service Lasso. Do these in order.

| Step | Guide | What you prove |
| --- | --- | --- |
| 1 | [Beginner Todo app](beginner-todo-app.md) | Lasso is running, Admin is healthy, you can sign in, create a todo, refresh, and see it persist |
| 2 | [Make the Todo app durable](make-todo-app-durable.md) | The same app keeps data in a managed PostgreSQL service across stop/start |
| Visual demo | [Quick start](../quick-start.md) | Optional Admin + Echo tour if you want a browser-only first look |

After that: [Configure and recover a service](../operate-your-service.md), [package your app](../package-your-app.md), or [browse services](../service-catalog.md).
