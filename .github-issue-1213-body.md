Part of #822.

## Purpose

Close the leftover HTTP durable-mutation slice of the action permission/audit identity model.

This does not re-implement landed HTTP action-run (#826 / PR #1119), lifecycle UI decisions (#1026 / PR #1173), or in-process CLI/scheduler/recovery-monitor enforcement (#1207 / PR #1212 / AC-4CC). Children #826 and #1207 stay CLOSED.

## Problem

Several Core HTTP routes still mutate durable state and append audit events with actor `"unknown"` instead of resolving the trusted request-policy actor and calling `enforcePermission`:

- `POST /api/updates/check`
- `POST /api/services/:serviceId/setup/run` and `/setup/run/:stepId`
- `POST /api/services/:serviceId/recovery/doctor`
- `POST /api/services/:serviceId/update/download`
- `POST /api/services/:serviceId/update/install`
- `POST /api/runtime/actions/:action` for `startAll`, `stopAll`, `autostart`, and `reload`

Those routes can mutate without a resolved actor, a permission decision, or confirmation for dangerous work.

## Required behaviour

- Resolve the actor from trusted runtime request context (`local-root`, `local-token`, or `zitadel-user`). JSON-body actor claims are not authority.
- Call the existing `enforcePermission` helper before mutation.
- Deny ungranted callers without mutation.
- Dangerous/elevated work (`update/install`, runtime `stopAll`, runtime `reload`) requires explicit confirmation.
- Audit allow/deny/confirmation through the existing store with the resolved actor id. Never persist secret values.
- Local-root loopback works without ZITADEL. Remote requires ZITADEL or an explicit local token.

## Acceptance criteria

- Granted local-root or local-token can run the listed HTTP mutations; viewer/unmapped ZITADEL is denied without mutation.
- Sensitive update install, runtime stopAll, and runtime reload without confirmation are denied.
- Audit records the resolved actor identity, permission decision, confirmation, and outcome. Actor is never `"unknown"` for these routes.
- Tests prove allow, deny, confirmation, and audit identity with no secret values in evidence.
- Parent #822 remains open for remaining CLI commands.
