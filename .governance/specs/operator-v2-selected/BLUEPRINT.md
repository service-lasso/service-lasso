## B: public operator v2 contract

Use a new explicitly versioned namespace /api/operator/v2; preserve legacy route names, fields, status conventions and existing v1 envelopes. Version is an exact string, not an open-ended major comparison. V2 uses shared closed DTO codecs detailed in CODECS-AND-STATE. No raw ServiceManifest, command/args/env/globalenv, arbitrary policy object, filesystem path, secret reference, authentication diagnostic, process command line, provider download URL or private actor object is a public projection. Names and descriptions remain bounded, classified operator display fields; a redacted:true flag or regex alone is insufficient. Secret-safe summaries come from enumerated messages and approved metadata selectors, not arbitrary error.message.

A discovery response exposes version, supportedJourneys, mutationSemantics, limits and metadataRevision. Each capability has id, exactly-three-key availability={supported,available,reasonCode:null|AvailabilityReason} as defined in CODECS, requiredProfile, requiredScopes, confirmationPolicy and bindingRequirements. Metadata availability is generated from the actual installed all-writer implementation contract and current trusted actor entitlement; never assert available because a legacy action name exists. Capability unsupported is distinct from unavailable, permission denied and stale. Reload remains unavailable where not implemented. Check/download explicitly advertise cancellation support; the five direct lifecycle actions explicitly advertise unsupported cancellation. Missing or unknown capabilities fail closed. Client does not invent aliases, fall back to an unsafe legacy mutation, or derive permission from visible buttons.
