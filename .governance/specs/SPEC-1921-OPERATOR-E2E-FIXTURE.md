# Shared ordinary CLI/TUI Core fixture — #1921

Active Development corrective slice for ordinary CLI/TUI E2E. This fixture is
independent of protected native authoring, operator-v2 programme #1681, packaged
qualification, immutable release and GA. It must not fabricate API responses.

E2E-FIXTURE-1: Require --core-dir, exact --expected-core-revision and an absent
absolute --output-dir. Validate selected checkout HEAD and clean tracked/untracked
source before loading its artifact. Source mode requires explicit --build-core,
records actual Node/npm/compiler versions and build command/result, hashes source
inputs and compiled JS closure. A failed build cannot load stale dist. Unqualified
mode requires --allow-unqualified-artifact plus exact
--expected-core-artifact-sha256; receipt never labels it source-built PASS.

E2E-FIXTURE-2: Controller launches one clean-environment child with private HOME,
XDG, workspace, services, registries and cache paths. Child uses the actual
supported SERVICE_LASSO_LOCAL_ADMIN_TOKEN generated by crypto.randomBytes.
createApiServer plus awaited waitForApiServerInitialization, manual loopback port0
and false autostart/monitor/updateScheduler implement ordinary smoke only.
Unqualified older artifacts may lack the initialization API; receipt records that
limitation. Verify actual security local-token actor versus local-root without
credential. No broker bootstrap, existing runtime restart or fixture API shim.

E2E-FIXTURE-3: Private output root0700 and connection.json0600 contain url/token.
stdout only ready:true,connectionFile,receiptFile. Public receipt binds schema1,
coreRevision,coreArtifactSHA256,url,stage,status,classification,tools and cleanup.
No token in receipt/stdout/stderr. Never log raw child startup errors.

E2E-FIXTURE-4: stdin stop or EOF, finite deadline and signals stop the owned server,
await initialization and close/owned connections, remove private credential and
record verified cleanup. Parent forwards stop and awaits owned child exit. Failed
startup closes any server and removes credentials; preserve public failure evidence.
Test actual privacy, invalid provenance, occupied output, broken import/init,
read-only real Core response and bounded teardown. Meaningful fixture-module tests
are fixture-class evidence only. Real source integration requires actual build and
source/artifact identity; old dist receives only unqualified artifact classification.

Reuse the shipped direct-server pattern in tests/fixtures/durable-lifecycle-http-peer.mjs
and tests/durable-lifecycle-http.test.js. Shared standalone helper adds cross-repo
selection/provenance/control, without copying server implementations. Full lifecycle
fixture (actual process, control service preservation) stays separate from smoke.
Root independently reviews exact source and applicable source-build scope before
execution. Normal signed PR/develop merge, postmerge integration and issue closure
remain required. No native source programme execution gate is silently waived.
