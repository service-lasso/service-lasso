Active Development spec. Issue #1619 / #1613 / #1562. Architecture: [ADR-001](../decisions/ADR-001-two-os-release-evidence.md). Parent release gates: SPEC-007 AC-7F/7G/7H. ## R1 — closed immutable policy and scope (C1/C4)

Policy top-level keys are exactly `schema, policyId, ownerDecision, requiredPlatforms, deferredPlatforms, requirementsRevision`. Schema is `service-lasso.ga-platform-scope.v1`; policyId `ga-windows-linux-2026-10-04`. Owner decision keys exactly `date, issue, authority`, values fixed by the checked-in policy. Requirements revision keys exactly `repository, commit, path`, identifying actual owner-scope source. Required order exactly `[win32,linux]`; deferred order exactly `[darwin]`. Hash the exact checked-in UTF-8 bytes with LF; no reserialization or newline normalization before digest comparison. Canonical source file and its separately recorded digest are reviewed source authority, never a caller-provided object.

Every new scope object has exactly `policyId, policySha256, policySource, requiredPlatforms, deferredPlatforms`. policySource keys exactly `repository, commit, path, blob`; repository is Core, path `.governance/project/ga-platform-scope.json`, commit and blob actual lowercase 40 hex, digest lowercase 64 hex. Exact Git blob bytes and SHA-256 must match the independently source-owned allowlist. Satellite copies are byte-identical with that immutable provenance; references pin the same tuple. Missing, unknown, altered, duplicated or reordered platforms, mixed source/digest or caller/environment-selected scope deny. No default from absent evidence. Source-approved dispatch is keyed by evidence schema plus policy digest, never just platform count.
