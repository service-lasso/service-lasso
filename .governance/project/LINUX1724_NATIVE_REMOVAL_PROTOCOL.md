## Genuine original-handle closure before exclusion

SETTLED is not yet writer exclusion. Original descriptors can run filesystem flush/release callbacks on close or process exit: at the selected kernel, fs/open.c's close calls filp_flush and fput_close_sync; fs/file_table.c's final release calls filesystem release, and ext4/file.c can allocate delayed-allocation blocks on release. Therefore terminal policy never permits a surviving original descriptor to be closed after SEALED. The transaction eliminates those descriptors and their W0 effects first; S retains its separately owned custody descriptors. S closing a pidfd_getfd inspection duplicate does not close W0's slot.

1. S closes original acquisition/launch authority in its genuine inception entry gate before requesting drain. It rejects original open/dup/transfer/rebinding/new mappings and unexpected reference acquisition from then on, without modifying syscall registers or returning fabricated completion. Already entered original operations must complete and account for their actual results under existing deadlines. Any unexpected attempted acquisition retains failure; there is no automatic retry under wider permissions. This gate remains closed through TSYNC and terminal shutdown.
2. The explicit adapter owns a finite original FileHandle/stream/raw-FD register for every source-enumerated fixture/custody call. It waits for pending actual fs operations and their callbacks, then invokes each actual owner object's normal close exactly once. Node FileHandle.close must run its real reference-count, Promise, close-event and native uv_fs_close completion path; stream close waits for its real finish/close contract. No direct native close behind a live FileHandle, forged closed flag, mocked Promise or GC-based cleanup. All original custody reads/verification after this point are S-held adapter operations, so a closed W0 handle is never later used as authority. An unknown native descriptor has no guessed owner or forced-close repair: retain failure.
3. While genuine closes run, S traces the actual main and required libuv worker threads with the closed acquisition gate. Their original syscalls must match the finite pending-close ledger; other threads remain parked except specifically accounted memory-only Node completion/wakeup work. S observes actual close entry/exit, object binding and errno. Node errors are delivered to their original callbacks and retained, not cleared by successful filesystem state. W0 cwd/root/executable/runtime mappings are immutable non-original objects from inception and cannot become originals; no original directory capability may remain through cwd/root or mappings. Outstanding original I/O, deferred release, unknown reference or ambiguous completion retains failure. ## Selected parked-state algorithm

S's genuine inception syscall ledger records entry/exit, native stop kind, full arguments, relevant FD object identity and clone/exec/lifetime events. W0 clone permits only the admitted pthread flag set with shared VM/files/sighand and same thread group; clone3 is denied with real ENOSYS and the admitted libc fallback is checked. W0 fork/vfork/exec and unshare are unavailable; S performs genuine registered helper/child launches. No external process shares W0's file table or original mappings.

PTRACE_INTERRUPT is used only to obtain an actual stop. Its return is never the proof. Accepted classes are:

| Class | Required source/native proof |
|---|---|
| SYSCALL_ENTRY | Genuine entry stop, complete preceding exit/effect ledger, no unresolved restart/async/original effect. Inception SECCOMP work already active. Resumption reaches seccomp after ptrace entry in the selected kernel. |
| USER_MEMORY_ONLY | Actual event stop with a completed preceding syscall and no active original effect. Original file mappings/device/async/cross-process paths are excluded from inception; stopped userspace can only modify non-original memory. |
| MEMORY_ONLY_BLOCKED | Actual interrupt/event/exit stop with the last recorded in-flight operation restricted to the selected wait catalog below. Every argument/object and restart path is accounted; its existing or restarted operation cannot access or mutate an original object. |
| UNKNOWN | Missing stop/entry/exit, D-state or original-capable in-flight operation, unknown object, restart/effect, new thread or mismatched lifetime. Retain failure; no inventory/delete. |

MEMORY_ONLY_BLOCKED permits only: futex wait/wait-bitset on W0's non-original memory; epoll_wait/epoll_pwait/epoll_pwait2 on the actual held eventpoll object; clock_nanosleep/nanosleep; and recvmsg on the authenticated fixed native control socket when S's operation ledger proves no pending original effect and the credential-only channel contract below proves no descriptor transfer. Epoll subscriptions are verified against the immutable admitted control/pipe/eventfd catalog; no unknown/device/inotify/original access callback is admitted. No write, file read/open/stat/rename/unlink/fsync/ioctl, descriptor-acquiring call, signal/control operation or generic syscall is a memory-only wait.

An interrupt may return or restart a wait. That is harmless only because the selected original wait and every possible restart-block target in the entire inception history are from this non-original wait catalog. poll/ppoll/select/pselect are denied or rejected from inception before original writes; do_restart_poll saves a mutable userspace pollfd array and re-resolves numeric slots, so current-syscall sampling never clears its prior history. S never rewrites registers/results or fabricates EINTR/completion. A pending original-capable call must genuinely settle under its original deadline, then reach a known entry/user stop; otherwise retain. The exact kernel's futex/epoll/signal/restart call graph and the admitted libc/libuv/V8 wait implementation belong to whole source review; unexpected restart targets fail the profile. Restart_syscall is allowed only for this certified non-original restart history, not as a universal bypass. No requirement that idle futex threads spontaneously return.

While releasing the barrier thread, S still gates its actual syscall entries: only installing the exact terminal filter and fixed control sendmsg/recvmsg handshake is permitted until it is reparked. The kernel install result and actual per-thread introspection must agree. Group exit/threads exiting during TSYNC, an unexpected filter chain or incomplete census is FAILED. Threads born before gate closure remain in the native ledger; no creation can be resumed during sealing. A task-list/cgroup comparison corroborates the exact event history but does not replace it.
